# 💰 Telegram Bot для учета доходов

Простой и удобный Telegram-бот для отслеживания личных доходов и генерации месячных отчетов.

## 📋 Возможности

- ✅ Добавление записей о доходах с описанием
- 📊 Генерация месячных отчетов
- 📈 Просмотр истории всех доходов
- 💾 Автоматическое сохранение данных
- 🔒 Персональные данные для каждого пользователя
- 🇷🇺 Полностью на русском языке
- 🎨 Удобное меню с кнопками и эмодзи
- 📅 Выбор месяца для отчета через интерактивное меню

## 🚀 Установка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и придумайте имя и username для вашего бота
4. Сохраните полученный токен (выглядит примерно так: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Установка зависимостей

```bash
cd telegram-income-bot
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте файл `.env` и вставьте токен вашего бота:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Запуск бота

#### Способ 1: Обычный запуск

```bash
npm start
```

Для разработки с автоматической перезагрузкой:

```bash
npm run dev
```

#### Способ 2: Запуск через Docker

Создайте файл `.env` с токеном бота, затем:

```bash
docker-compose up -d
```

Для просмотра логов:

```bash
docker-compose logs -f
```

Для остановки:

```bash
docker-compose down
```

## 📱 Использование

Бот имеет удобное меню с кнопками - вам не нужно запоминать команды! Просто нажимайте на кнопки для управления.

### 🎛 Главное меню

После команды `/start` вы увидите главное меню с кнопками:

| Кнопка | Описание |
|--------|----------|
| 💰 Добавить доход | Добавить новую запись о доходе |
| 📊 Отчет за месяц | Показать отчет за текущий месяц |
| 📋 История | Показать последние 10 записей |
| 📅 Отчет за период | Выбрать месяц для детального отчета |
| 🗑 Очистить данные | Удалить все записи (с подтверждением) |
| ❓ Помощь | Показать справку |

### 💡 Как пользоваться

#### 1️⃣ Добавление дохода

1. Нажмите кнопку **💰 Добавить доход**
2. Введите сумму и описание через пробел
3. Примеры:
   - `5000 Зарплата за октябрь`
   - `1500.50 Фриланс проект`
   - `300 Бонус от заказчика`

#### 2️⃣ Просмотр отчета за текущий месяц

Нажмите кнопку **📊 Отчет за месяц** - бот покажет все доходы за текущий месяц с итоговой суммой.

#### 3️⃣ Просмотр отчета за любой месяц

1. Нажмите кнопку **📅 Отчет за период**
2. Выберите нужный месяц из списка (от января до декабря)
3. Бот покажет детальный отчет за выбранный месяц

#### 4️⃣ Просмотр истории

Нажмите кнопку **📋 История** - бот покажет последние 10 записей и общую статистику.

#### 5️⃣ Очистка данных

1. Нажмите кнопку **🗑 Очистить данные**
2. Подтвердите действие кнопкой **✅ Да, удалить все**
3. Или отмените кнопкой **❌ Отмена**

### 🎮 Командный режим (альтернатива)

Если вы предпочитаете команды, они тоже доступны:

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и показать главное меню |
| `/add <сумма> <описание>` | Добавить доход |
| `/report` | Отчет за текущий месяц |
| `/history` | Последние 10 записей |
| `/clear` | Очистить все данные |
| `/help` | Справка |

## 💾 Хранение данных

Данные хранятся в файле `incomes.json` в формате:

```json
{
  "users": {
    "123456789": {
      "incomes": [
        {
          "amount": 5000,
          "description": "Зарплата",
          "date": "2024-10-29T12:00:00.000Z",
          "timestamp": 1698580800000
        }
      ]
    }
  }
}
```

Каждый пользователь имеет свой собственный набор данных, идентифицируемый по Telegram ID.

## ❓ Часто задаваемые вопросы

**Q: Безопасны ли мои данные?**
A: Все данные хранятся локально на вашем сервере в файле `incomes.json`. Никакие данные не передаются третьим лицам.

**Q: Могу ли я использовать бота с нескольких аккаунтов?**
A: Да, каждый пользователь Telegram имеет свои собственные данные, идентифицируемые по Telegram ID.

**Q: Что делать, если бот не отвечает?**
A: Проверьте, что бот запущен (`npm start`), токен указан правильно в `.env`, и у вас есть интернет-соединение.

**Q: Можно ли редактировать или удалять отдельные записи?**
A: В текущей версии эта функция не реализована, но вы можете добавить её самостоятельно или использовать команду `/clear` для полной очистки.
