# 💰 Telegram Bot для учета доходов

Простой и удобный Telegram-бот для отслеживания личных доходов и генерации месячных отчетов.

## 📋 Возможности

- ✅ Добавление записей о доходах с описанием
- 📊 Генерация месячных отчетов
- 📈 Просмотр истории всех доходов
- 💾 Автоматическое сохранение данных
- 🔒 Персональные данные для каждого пользователя
- 🇷🇺 Полностью на русском языке

## 🚀 Установка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и придумайте имя и username для вашего бота
4. Сохраните полученный токен (выглядит примерно так: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Установка зависимостей

```bash
cd telegram-income-bot
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте файл `.env` и вставьте токен вашего бота:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Запуск бота

#### Способ 1: Обычный запуск

```bash
npm start
```

Для разработки с автоматической перезагрузкой:

```bash
npm run dev
```

#### Способ 2: Запуск через Docker

Создайте файл `.env` с токеном бота, затем:

```bash
docker-compose up -d
```

Для просмотра логов:

```bash
docker-compose logs -f
```

Для остановки:

```bash
docker-compose down
```

## 📱 Использование

### Основные команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `/start` | Приветствие и список команд | `/start` |
| `/add <сумма> <описание>` | Добавить доход | `/add 5000 Зарплата` |
| `/report` | Отчет за текущий месяц | `/report` |
| `/report <месяц> <год>` | Отчет за конкретный месяц | `/report 10 2024` |
| `/history` | Последние 10 записей | `/history` |
| `/clear` | Очистить все данные | `/clear` |
| `/help` | Справка по командам | `/help` |

### Примеры использования

#### Добавление дохода

```
/add 5000 Зарплата за октябрь
/add 1500.50 Фриланс проект
/add 300 Бонус от заказчика
```

#### Получение отчетов

```
/report                  # Отчет за текущий месяц
/report 10 2024         # Отчет за октябрь 2024
/report 1 2024          # Отчет за январь 2024
```

## 💾 Хранение данных

Данные хранятся в файле `incomes.json` в формате:

```json
{
  "users": {
    "123456789": {
      "incomes": [
        {
          "amount": 5000,
          "description": "Зарплата",
          "date": "2024-10-29T12:00:00.000Z",
          "timestamp": 1698580800000
        }
      ]
    }
  }
}
```

Каждый пользователь имеет свой собственный набор данных, идентифицируемый по Telegram ID.

## ❓ Часто задаваемые вопросы

**Q: Безопасны ли мои данные?**
A: Все данные хранятся локально на вашем сервере в файле `incomes.json`. Никакие данные не передаются третьим лицам.

**Q: Могу ли я использовать бота с нескольких аккаунтов?**
A: Да, каждый пользователь Telegram имеет свои собственные данные, идентифицируемые по Telegram ID.

**Q: Что делать, если бот не отвечает?**
A: Проверьте, что бот запущен (`npm start`), токен указан правильно в `.env`, и у вас есть интернет-соединение.

**Q: Можно ли редактировать или удалять отдельные записи?**
A: В текущей версии эта функция не реализована, но вы можете добавить её самостоятельно или использовать команду `/clear` для полной очистки.
